# Git Tips 001

## Remove tracked files from version control

```
git rm --cached [file or folder]
```

Then add `[file or foler]` in `.gitignore` or in `[repo root]\.git\modules\[module repo]\info\exclude`.

```
echo "[file or foler]" >> .gitignore
echo "[file or foler]" >> ..\.git\modules\[module repo]\info\exclude
```

## Restore submodules

When submodules have new commits, but you don't want to do uplift. For example,

```
> git status
On branch master
Your branch is up to date with 'origin/master'.

Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
  (use "git restore <file>..." to discard changes in working directory)
        modified:   bob (new commits)
        modified:   cicd-config (new commits)

no changes added to commit (use "git add" and/or "git commit -a")
```

The solution is to run the command `git submodule update --init --recursive`.

```
> git submodule update --init --recursive && git status
Submodule path 'bob': checked out '3b0ed618a0112f824726d8fee2ff525248045734'
Submodule path 'cicd-config': checked out 'f8f91b9295a7f99e14555da32857b28f687ef443'

On branch master
Your branch is up to date with 'origin/master'.

nothing to commit (use -u to show untracked files)
```
