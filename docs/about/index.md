## Philosophy

- **Clarity over cleverness** — code should read like well-written prose
- **No broken windows** — fix small problems before they compound
- **Automate the repeatable** — if you do it twice, script it
- **Learn by building** — theory without practice is empty; practice without theory is blind
- **Aesthetic matters** — ugly code harbors bugs; beautiful code invites understanding
